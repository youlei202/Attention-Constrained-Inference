# ACLI (Attention-Constrained Leaderless Inference) — Reproducible Experiments

This repo is a lightweight, reproducible experiment suite for the ACLI paper:
**"Attention-Constrained Leaderless Inference: Fundamental Limits Under Log-Loss"**.

The design goal is **clean modular code** + **strict reproducibility** + **simple experiment entrypoints**
(each experiment is a standalone `python experiment/00_xxx.py` without CLI args).

## Repository structure

```text
acli_repo/
├─ acli/                       # core library (high cohesion / low coupling)
│  ├─ __init__.py
│  ├─ utils.py                  # seeding, device selection
│  ├─ screening.py              # screening models (e.g., Gaussian mixture)
│  ├─ policy.py                 # top-B / random verification policies
│  └─ benchmark.py              # theory lines + Monte Carlo helpers
├─ data/                        # datasets (if any). (kept empty by default)
├─ experiment/                  # runnable scripts (no CLI args)
│  ├─ 00_benchmark_theory_vs_sim.py
│  ├─ 01_theorem6_upper_bound_hits.py
│  └─ 02_lemma4_enrichment_bound.py
├─ notebook/                    # visualization notebooks (save figures as vector PDF)
│  ├─ 00_benchmark_theory_vs_sim.ipynb
│  ├─ 01_theorem6_upper_bound_hits.ipynb
│  └─ 02_lemma4_enrichment_bound.ipynb
├─ result/
│  ├─ table/                    # per-run CSV outputs (cached for later plotting)
│  ├─ artifact/                 # optional saved artifacts
│  └─ figure/                   # vector PDF figures (generated by notebooks)
├─ requirements.txt
├─ .gitignore
└─ LICENSE (optional)
```

## Quickstart

```bash
pip install -r requirements.txt
```

Run experiments (writes CSVs to `result/table/`):

```bash
python experiment/00_benchmark_theory_vs_sim.py
python experiment/01_theorem6_upper_bound_hits.py
python experiment/02_lemma4_enrichment_bound.py
```

Then open the matching notebook to generate **PDF vector figures** into `result/figure/`.

## What the “core” experiments cover

- **00_benchmark_theory_vs_sim**  
  Appendix A benchmark: compares the **asymptotic theory line** (single-letter / threshold form)
  with Monte Carlo simulation for  
  \(\mathbb{E}[\sum_{\ell=1}^B \eta_{(\ell)}]\).

- **01_theorem6_upper_bound_hits**  
  Simulates the expected number of “hits” (informative verified records) under top-B selection,
  and compares with the **Theorem 6 upper envelope** (in terms of \(J=I(T;Z)\)).

  Note: Theorem 6 is a *converse* (a ceiling). An experiment can validate it by showing
  empirical curves do not exceed it; it is not expected that typical curves track the ceiling.

- **02_lemma4_enrichment_bound**  
  Directly validates Lemma 4’s selection enrichment bound:
  \(P(T=1\mid S=1) \le p + \sqrt{\ln 2\, J / (2\alpha)}\).

## GPU acceleration

If you have `torch` installed and a CUDA GPU, you can extend the code to run larger Monte Carlo more quickly.
The current “core” experiments are CPU-friendly by default for portability.

## Reproducibility

- Each experiment sets a fixed seed.
- Outputs are saved as CSV with metadata (seed, timestamp, etc.).
- Notebooks only **read CSVs** and generate figures; no heavy computation in notebooks.
